# MPI Darsana — Revisi 5 — Jejak Kebijaksanaan

Media pembelajaran interaktif Darsana dengan enam materi Sad Darsana, pengantar berbentuk percakapan, peta belajar bertahap, kuis umpan balik per materi, aktivitas interaktif, kuis akhir dengan timer, skor dan pembahasan, infografis, refleksi, serta daftar pustaka.

## Menjalankan di komputer
1. Ekstrak file ZIP.
2. Buka folder hasil ekstraksi.
3. Klik dua kali `index.html` untuk membukanya di browser.
4. Pertahankan `index.html`, `style.css`, dan `script.js` dalam folder yang sama.

## Mengunggah ke GitHub Pages
1. Buat repository baru di GitHub.
2. Unggah `index.html`, `style.css`, `script.js`, dan README ke root repository.
3. Buka **Settings → Pages**.
4. Pilih **Deploy from a branch**, pilih branch `main` dan folder `/ (root)`, lalu simpan.

## Fitur
- Bubble percakapan pengantar bisa diklik untuk berpindah percakapan; tombol jelajah hanya muncul di percakapan terakhir.
- Materi enam aliran ditata ulang berdasarkan PDF acuan.
- Setiap materi memiliki tiga pertanyaan kuis umpan balik. Materi belum dapat ditandai selesai sebelum semua pertanyaan dijawab.
- Aktivitas interaktif mengambil 10 tantangan acak dari bank berisi 20 soal dengan beberapa tipe aktivitas.
- Kuis akhir memiliki 15 soal pilihan ganda, batas waktu 10 menit, skor, dan pembahasan.
- Jawaban refleksi tidak dikirim ke server dan tidak disimpan permanen; salin jawaban jika ingin menyimpannya.
- Daftar pustaka memuat informasi yang diberikan pengguna tanpa menambahkan detail bibliografi yang belum tersedia.


## Pembaruan revisi 5
- Materi pada halaman bab menggunakan lebar penuh; panel kuis umpan balik hanya muncul saat tombol di kiri bawah diklik.
- Panel umpan balik memiliki tombol tutup dan tombol penyelesaian materi di bagian bawah.
- Aktivitas benar/salah memakai opsi kotak dengan ikon centang dan silang. Tantangan susun kata menggunakan huruf-huruf acak untuk membentuk satu istilah.
- Kuis akhir memiliki durasi 30 menit.
- Catatan di bawah peta menjelaskan bahwa aktivitas interaktif dan kesimpulan tersedia setelah semua materi selesai.
- PDF Buku Ajar Darsana disertakan sebagai `Buku_Ajar_Darsana.pdf` dan dapat dibuka dari halaman Daftar Pustaka.
