# MPI Darsana — versi revisi awal

Website statis untuk GitHub Pages. Semua file berada di root:
- `index.html`
- `style.css`
- `script.js`

## Cara mencoba
1. Ekstrak ZIP.
2. Buka `index.html` di browser untuk mencoba fitur dasar.
3. Untuk penggunaan paling konsisten, unggah ketiga file ke root repositori GitHub Pages.

## Catatan
- Identitas, progres materi, refleksi, hasil kuis, dan sertifikat disimpan menggunakan `localStorage` pada browser/perangkat yang sama.
- Sertifikat dapat diunduh sebagai PNG; opsi PDF membuka dialog cetak browser, lalu pilih “Simpan sebagai PDF”.
- Materi dan bank soal pada versi ini masih berupa draf awal dan akan diperbarui setelah naskah final diberikan.
- Data lokal tidak tersinkron otomatis antarperangkat dan dapat hilang jika data situs dibersihkan.
